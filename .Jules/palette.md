## 2026-11-08 - Login Form Accessibility and Layout Insights
**Learning:** Missing box-sizing causes 100% width inputs to overflow their containers when padding is applied, creating a subtle misalignment. Empty error message containers fail to provide context, and missing autocomplete attributes hinder password managers.
**Action:** Always verify box-sizing on full-width inputs, provide descriptive text and role='alert' for error messages, and include appropriate autocomplete attributes on login fields.
